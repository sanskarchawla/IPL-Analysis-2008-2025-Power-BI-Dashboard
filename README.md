# 🏏 IPL Analysis (2008–2025) | Power BI Dashboard

## 📌 Project Overview

The **IPL Analysis Dashboard (2008–2025)** is an interactive Business Intelligence project developed using Microsoft Power BI to analyze historical Indian Premier League (IPL) data.

The dashboard provides insights into IPL seasons, team achievements, player performances, and tournament statistics. It transforms historical cricket data into meaningful visual insights, allowing users to explore different seasons and evaluate team and individual performances.

## 🎯 Project Objectives

- Analyze IPL statistics across seasons from 2008 to 2025.
- Identify season champions and runners-up.
- Evaluate team performance through season-wise standings.
- Analyze Orange Cap and Purple Cap winners.
- Identify top performers based on boundaries (4s and 6s).
- Provide an interactive platform for exploring IPL statistics.

## 📊 Dashboard Features

### 1. Season Analysis
- Interactive IPL season slicer.
- Season-wise champion and runner-up information.
- Total matches and teams participating.
- Total fours, sixes, and half-centuries.
 
### 2. Team Performance Analysis
- Team-wise points table.
- Matches played, wins, losses, and no-result matches.
- Season-wise team performance comparison.

### 3. Player Performance Analysis
- Orange Cap holder – Highest run scorer.
- Purple Cap holder – Highest wicket taker.
- Most fours by a player.
- Most sixes by a player.
- Player and team details.

### 4. Interactive Visualizations
- Dynamic season filtering.
- KPI cards.
- Team standings table.
- Player performance highlights.
- Visual elements for an engaging dashboard experience.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data preparation and transformation.
- **DAX** – Measures, calculated KPIs, and analytical calculations.
- **Data Visualization** – Interactive reports and performance indicators.

## 💡 Business Insights

This dashboard helps users:
- Understand how IPL teams perform across different seasons.
- Identify the most successful teams and individual players.
- Compare batting and bowling achievements.
- Explore historical tournament trends.
- Evaluate team standings and season outcomes.
